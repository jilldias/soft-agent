
# Soft Agente

**AI-Powered Software Engineering Mentor**

O Soft Agente é um projeto de agente de Inteligência Artificial desenvolvido para atuar como mentor durante o processo de aprendizagem e desenvolvimento de software.

Sua proposta é acompanhar o desenvolvedor em projetos reais, auxiliando na compreensão de requisitos, elaboração de documentação, decisões arquiteturais, implementação, debugging e revisão de código.

Diferentemente de ferramentas que priorizam a geração automática de código, o Soft Agente busca ensinar o desenvolvedor a pensar, projetar e construir soluções de software.

## Objetivo

Promover o desenvolvimento da autonomia técnica por meio de orientação contextual, aprendizagem progressiva e aplicação prática de conceitos de Engenharia de Software.

## Princípios fundamentais

- **Aprendizagem:** priorizar a compreensão dos conceitos em vez da simples entrega de soluções.
- **Autonomia:** preservar o protagonismo do desenvolvedor nas decisões e implementações.
- **Raciocínio crítico:** estimular a análise de problemas e a avaliação de alternativas.
- **Desenvolvimento incremental:** dividir problemas complexos em etapas menores.
- **Documentação:** utilizar requisitos, regras de negócio e decisões arquiteturais como referência.
- **Transparência:** explicar recomendações, limitações e consequências técnicas.

## Funcionalidades planejadas

- Gerenciamento de projetos e documentação.
- Interpretação de requisitos e regras de negócio.
- Orientação sobre arquitetura e organização de código.
- Acompanhamento contextual do desenvolvimento no VS Code.
- Sugestões pedagógicas proativas.
- Sistema progressivo de dicas e explicações.
- Apoio à identificação e resolução de erros.
- Revisão de código e acompanhamento da evolução técnica.

## Tecnologias previstas

| Componente | Tecnologia |
|---|---|
| Backend | Python / FastAPI |
| Extensão IDE | TypeScript / VS Code API |
| Banco de dados | MariaDB |
| Comunicação | REST API |
| Infraestrutura | Podman / Debian |
| Acesso privado | Tailscale |
| Testes | Pytest |

As tecnologias e decisões arquiteturais ainda estão sujeitas à validação durante o desenvolvimento.

## Filosofia do projeto

> O agente não deve desenvolver o software por mim; deve me ensinar a desenvolver o software.

O Soft Agente não pretende substituir o raciocínio do programador. Seu papel é funcionar como uma ferramenta de apoio ao aprendizado, ajudando o desenvolvedor a adquirir conhecimento e independência técnica.
